🎓 ГАЙД: Як AI-агент чистить Instagram від ботів — без ризику для акаунта

Я подивилася на свої підписки в Instagram і побачила сотні акаунтів без фото, без постів, з ніками типу anna_92834. Відписуватися руками — це кілька вечорів. Тому я доручила це агенту. Ось як зробити так само за 30 хвилин налаштування.

---

**Чому не можна «просто через API»**

В офіційному API Instagram немає підписки та відписки — ці методи прибрали ще у 2018 році. Сервіси-«чистильники» просять пароль і порушують правила Instagram, за це блокують акаунт. Єдиний безпечний шлях — браузер на твоєму компʼютері, де ти вже залогінена: Instagram бачить звичайні кліки.

Тому схема така: Claude Code + Playwright (бібліотека, що керує Chrome) + окремий профіль браузера. Код зберігається, запускаєш коли завгодно.

**Що буде в результаті**

Чотири скрипти, кожен — один крок:
1. login — один раз входиш в Instagram у чистому вікні Chrome
2. collect — агент збирає список підписок і дані по кожному профілю
3. score — рахує «бал бота» і показує кандидатів
4. unfollow — відписується тільки від тих, кого ти затвердила, з лімітами

Ключове слово — **затвердила**. Агент нічого не видаляє сам. Він готує список, ти дивишся очима, і лише потім він працює.

---

**Крок 1. Встанови інструменти**

Потрібні Node.js (nodejs.org, кнопка LTS) і Claude Code:

```
npm install -g @anthropic-ai/claude-code
```

**Крок 2. Скачай готові скрипти**

Я виклала все у відкритий репозиторій клубу. У терміналі одним блоком:

```
git clone https://github.com/HelenNikulina/aiclub.git
cd aiclub/instagram-cleanup
npm install
```

Детальна інструкція лежить поруч: github.com/HelenNikulina/aiclub/tree/main/instagram-cleanup

**Крок 3. Впиши свій нік**

Відкрий config.js і заміни ЗАМЕНИ_НА_СВОЙ_НИК на свій нік без @. Або запусти в цій папці `claude` і скажи: «впиши мій нік у config.js». Це єдиний файл, який треба правити руками.

**Крок 4. Увійди один раз**

```
npm run login
```

Відкриється чисте вікно Chrome — окремий профіль, твій звичайний браузер не чіпається. Заходиш як зазвичай, бачиш стрічку, закриваєш вікно. Сесія збереглася, пароль скрипти не бачать. Мову Instagram краще переключити на English — так кнопки шукаються надійніше.

**Крок 5. Збери дані**

```
npm run collect
```

Агент прокрутить список Following, потім зайде на кожен профіль і запише: пости, підписники, підписки, імʼя, біо. Пауза 3–7 секунд між профілями, приблизно 400 профілів за годину. Можна перервати і запустити знову — продовжить з того ж місця.

**Крок 6. Отримай кандидатів**

```
npm run score
```

Бал бота рахується так: акаунт видалений — 5, нуль постів — 2, підписок у 10 разів більше, ніж підписників — 2, менше 30 підписників, порожнє біо, немає імені, нік з цифрами — по 1. Усе з балом 3+ потрапляє в data/candidates.csv із посиланнями. Відкрий у Excel і викресли живих людей: у знайомого теж може бути нуль постів.

**Крок 7. Затверди список**

Створи файл data/approved.txt, ніки по одному в рядку. Скрипт відписки читає тільки його. Швидкий варіант — сказати Claude Code: «візьми з candidates.csv усіх з балом 5+ і запиши в approved.txt».

**Крок 8. Відписка**

```
npm run unfollow
```

Агент тисне Following → Unfollow, чекає випадкові 25–70 секунд і йде далі. Ліміти зашиті в код: 40 на годину, 120 на день. Коли ліміт вичерпано — сам зупиняється. Запускай раз на день, поки список не скінчиться.

---

**Підводні камені**

⚡ **Instagram змінює інтерфейс** кілька разів на рік, і кнопка раптом називається інакше. Для цього і потрібен Claude Code: запусти `claude` у папці скриптів і напиши «npm run unfollow падає, ось помилка, полагодь». Він виправить код, і все знову працює по кнопці.

⚡ **Не піднімай ліміти.** 40 на годину — це рівень, який виглядає як ручна робота. Якщо побачила «Action blocked» — скрипт зупиниться сам, пауза мінімум доба.

⚡ **Перші два дні — по 20–30 відписок.** Дай Instagram звикнути, що ти «активно чистиш підписки».

⚡ **Видалити ботів з підписників** — та сама схема, але інша кнопка (Remove follower). Якщо цікаво — напишіть у коментарях, зроблю продовження.
