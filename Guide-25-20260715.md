Для будь-кого, хто регулярно робить презентації: інвесторам, клієнтам, на вебінар, для внутрішньої команди. Результат — не «чернетка, яку ще треба допиляти», а готовий до відправки матеріал із чіткою структурою, аргументами та візуальною логікою.

Єдина умова — ви маєте розуміти свій продукт і аудиторію. Claude Code зробить структуру і текст, але ваша експертиза — це вхідні дані.

**Покрокова інструкція**

**Крок 1. Зберіть вхідні дані в один файл**

Створіть текстовий файл із ключовою інформацією. Не треба красиво — треба конкретно. Що продаєте, кому, яка головна проблема клієнта, чим ви відрізняєтесь, 2-3 кейси або цифри.

Збережіть як `brief.md` у робочій папці.

**Крок 2. Дайте Claude Code промт на структуру**

Відкрийте Claude Code і дайте йому цей промт (скопіюйте та адаптуйте під себе):

```
Прочитай файл brief.md. На основі цих даних створи структуру продаючої презентації з 10-12 слайдів. Формат: для кожного слайда — заголовок, основний меседж (1-2 речення), та bullet points (2-4 штуки).

Структура має включати:
1. Титульний слайд із hook-фразою
2. Проблема клієнта (біль, який він відчуває щодня)
3. Наслідки бездіяльності (що буде, якщо не вирішити)
4. Рішення — ваш продукт/послуга
5. Як це працює — 3-4 кроки
6. Конкретні результати / кейси з цифрами
7. Чому саме ви (відмінності від конкурентів)
8. Тарифи або формат роботи
9. Відповіді на типові заперечення
10. Call to action — чіткий наступний крок

Пиши мовою аудиторії: [українська/російська/англійська].
Тон: впевнений, конкретний, без води.
Збережи результат у файл presentation_structure.md
```

**Крок 3. Перевірте структуру та скоригуйте**

Прочитайте те, що вийшло. Зазвичай 80% — вже добре. Скажіть Claude Code, що змінити: «Замінь слайд 3 на конкретний кейс компанії X», «Додай слайд про ROI після слайда з результатами». Не переписуйте самі — давайте точкові правки.

**Крок 4. Згенеруйте фінальний контент**

Коли структура влаштовує, дайте наступну команду:

```
На основі presentation_structure.md напиши повний текст для кожного слайда. Для кожного слайда:
- Заголовок (до 7 слів)
- Підзаголовок або основна теза (1 речення)
- Bullet points з конкретикою (цифри, факти, не абстракції)
- Нотатки спікера: 2-3 речення — що сказати усно на цьому слайді

Збережи у файл presentation_final.md
```

**Крок 5. Створіть візуальну презентацію**

Тепер у вас є повний текст. Далі є два шляхи:

— Якщо потрібен швидкий результат: скопіюйте текст у Google Slides або Canva та розкидайте по слайдах. Із готовим текстом це займає 5 хвилин.

— Якщо хочете автоматизувати повністю: попросіть Claude Code згенерувати HTML-презентацію або код для python-pptx, який створить .pptx файл автоматично.

**Крок 6. Фінальна перевірка — «тест ліфта»**

Дайте Claude Code ваш фінальний файл і попросіть:

```
Прочитай presentation_final.md і дай чесну критику: чи зрозуміло з перших 3 слайдів, що я продаю і навіщо це клієнту? Чи є конкретика, чи тільки загальні слова? Що найслабше?
```

Це працює як свіжий погляд колеги, який не боїться сказати правду.
