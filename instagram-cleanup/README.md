# Чистка подписок Instagram от ботов — Claude Code + Playwright

Полуавтомат: скрипты собирают список подписок, оценивают каждый профиль,
показывают кандидатов, **ты подтверждаешь глазами**, и только потом идёт
отписка с лимитами и паузами. Всё работает на твоём компьютере, в отдельном
профиле Chrome, куда ты один раз залогинишься.

Claude Code здесь нужен для двух вещей: поставить всё одной командой и
чинить скрипты, когда Instagram поменяет вёрстку (он меняет её часто).

## Что понадобится

- Компьютер с Google Chrome (Mac или Windows).
- Node.js 20+ — https://nodejs.org (кнопка LTS, дальше «Далее, далее»).
- Claude Code — `npm install -g @anthropic-ai/claude-code`.
- Git — на Mac уже есть, на Windows: https://git-scm.com/download/win.

## Шаг 0. Скачать папку со скриптами

Терминал (Mac: Terminal, Windows: PowerShell), одним блоком:

```bash
git clone https://github.com/HelenNikulina/aiclub.git
cd aiclub/instagram-cleanup
npm install
```

`npm install` ставит Playwright. Браузер он не качает — используем твой Chrome.

## Шаг 1. Вписать свой ник

Открой `config.js` в любом редакторе и замени `ЗАМЕНИ_НА_СВОЙ_НИК` на свой
ник без `@`. Больше там ничего трогать не нужно.

Или попроси Claude Code — прямо в этой папке:

```bash
claude
```

и напиши: «впиши в config.js мой ник: такой-то».

## Шаг 2. Один раз войти в Instagram

```bash
npm run login
```

Откроется чистое окно Chrome (отдельный профиль, твой обычный Chrome не
трогается). Войди как обычно, включая код из SMS, если спросит. Когда
увидишь ленту — просто закрой окно. Cookies сохранились в папке
`~/ig-cleanup-profile`, больше логиниться не нужно.

**Важно:** переключи язык Instagram на English (Settings → Language). Кнопки
в скриптах ищутся по английским, русским и украинским названиям, но English
самый надёжный.

## Шаг 3. Собрать данные по подпискам

```bash
npm run collect
```

Скрипт откроет твой список «Following», прокрутит его до конца и сохранит
все ники. Потом зайдёт на каждый профиль и запишет: публикации, подписчики,
подписки, имя, био, закрыт ли аккаунт. Между профилями пауза 3–7 секунд.

Скорость: примерно 400–500 профилей в час. За один запуск проверяется
до 400 (настройка `collectMaxPerRun`). Если подписок больше, запусти
команду ещё раз — она продолжит с места остановки. Можно прервать Ctrl+C.

## Шаг 4. Получить список кандидатов

```bash
npm run score
```

Считает «балл бота» по каждому профилю:

| Признак | Балл |
|---|---|
| Аккаунт удалён или заблокирован | 5 |
| 0 публикаций | 2 |
| Подписок в 10+ раз больше, чем подписчиков | 2 |
| Меньше 30 подписчиков | 1 |
| Больше 3000 подписок | 1 |
| Пустое био | 1 |
| Нет имени | 1 |
| Ник вида `anna_92834` | 1 |

Всё, что набрало 3 и больше, попадает в `data/candidates.csv`. Открой файл
в Excel или Numbers, там ссылка на каждый профиль. Пройдись глазами: у
живого человека может быть 0 постов и пустое био, такие вычеркни.

Порог можно менять в `config.js` (`botThreshold`).

## Шаг 5. Утвердить список

Создай файл `data/approved.txt` и впиши ники по одному в строке, от кого
отписаться:

```
anna_92834
best.shop.2019
promo_acc_777
```

Скрипт отписки читает **только этот файл**. Кого в нём нет, тот не тронется.

Быстрый способ: попроси Claude Code «возьми из candidates.csv всех с баллом
5 и выше и запиши в approved.txt».

## Шаг 6. Отписаться

```bash
npm run unfollow
```

Скрипт заходит на каждый профиль из списка, жмёт «Following» → «Unfollow»,
ждёт случайные 25–70 секунд и идёт дальше. Лимиты:

| Параметр | Значение |
|---|---|
| В час | 40 |
| В день | 120 |
| Пауза между отписками | 25–70 сек |

Когда лимит исчерпан, скрипт сам останавливается и пишет, что продолжит
позже. Запускай раз в день, пока список не кончится. Если Instagram показал
«Try again later» или «Action blocked», скрипт остановится сам: пауза
минимум сутки, лимиты не поднимать.

Лог всех действий в `data/unfollow-log.json`, повторно один и тот же
аккаунт не трогается.

## Если что-то сломалось

Самая частая причина: Instagram обновил интерфейс и кнопка называется
иначе или лежит в другом месте. Для этого и нужен Claude Code. В папке
скриптов:

```bash
claude
```

и опиши словами: «npm run unfollow падает с такой-то ошибкой, вот текст
ошибки, почини». Он поправит селекторы в `unfollow.js` или `collect.js`,
код останется у тебя, и дальше всё снова работает по кнопке.

## Что можно поменять в config.js

- `collectDelaySec`, `unfollowDelaySec` — паузы.
- `unfollowMaxPerHour`, `unfollowMaxPerDay` — лимиты. Вниз можно, вверх не стоит.
- `botThreshold` — порог балла.
- `useSystemChrome: false` — если Chrome не установлен, скрипт возьмёт
  Chromium из Playwright (нужно один раз выполнить `npx playwright install chromium`).

## Безопасность

- Пароль нигде не хранится: ты вводишь его сама в окне браузера, скрипты
  его не видят. Сессия живёт в папке `~/ig-cleanup-profile` на твоём диске.
- Папка `data/` и профиль в git не попадают (`.gitignore`).
- Instagram считает любую автоматизацию нарушением правил. Лимиты выше
  подобраны так, чтобы действия выглядели как ручные, но гарантии нет.
  Первые пару дней запускай понемногу, по 20–30 отписок.
